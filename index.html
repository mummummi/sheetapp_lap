실습 2 AI에게 키오스크 부탁하기

메모 칸은 신중하게자세한 고민이 시트에 남습니다. 최소 수집 원칙과 맞는지 생각해 보세요.
✨ Gemini 💬 ChatGPT 🟠 Claude
받은 코드, 바로 쓰기 전에시트 이름 '상담신청'과 열 순서가 코드 안에 그대로 있는지 눈으로 확인하세요.

AI가 막힐 때 · 예비 코드

🐻
학생이 부담 없이 누르는 키오스크

한 화면에 질문 하나 · 큰 색깔 타일 · 통통 튀는 곰 캐릭터 · 완료하면 색종이 🎉

AI 결과가 계속 안 될 때 쓰는 기본 코드입니다. 실습 1의 시트 그대로 동작하고, 교사용 확인 페이지(admin.html)까지 들어 있어요. index.html 맨 아래 '우리 학교에 맞게 바꾸는 곳'에서 학교 이름·반·선생님·분류를 고칠 수 있어요.

교사용 확인 페이지 · 처리상태를 버튼으로 '완료'

1

Code.gs 바꾸고 비밀번호 정하기

위 Code.gs로 바꾼 뒤 맨 위 ADMIN_PASSWORD = '1234'를 나만 아는 비밀번호로

2

HTML 파일 하나 더

[＋ › HTML] → 이름 admin → 위 admin.html 붙여 넣기

3

새 버전으로 배포

[배포 › 배포 관리 › ✏️ › 새 버전]. 학생용 주소는 그대로예요

4

주소 끝에 ?page=admin

…/exec?page=admin → 비밀번호 → '대기' 신청만 보이고 [완료]를 누르면 시트가 '완료'로

왜 비밀번호를 거나요?키오스크는 '모든 사용자'로 배포해서 주소를 아는 사람은 누구나 들어올 수 있어요. 신청 목록이 보이는 교사용 페이지는 비밀번호로 한 번 더 잠급니다(접근 권한 원칙).
⚠️ 비밀번호는 Code.gs에만Code.gs는 학생 화면에 보이지 않아요. admin.html이나 index.html에는 비밀번호를 적지 마세요.

오류 해결 도우미

코드를 고쳤는데 화면이 그대로예요
예전 버전이 배포 중입니다. [배포 › 배포 관리 › ✏️ 수정 › 버전: 새 버전 › 배포]. '새 배포'를 누르면 주소가 바뀌니 주의!
신청했는데 시트가 비어 있어요
탭 이름이 코드와 다릅니다. '상담신청' 철자와 띄어쓰기를 확인하세요. 시트를 새로 만들었다면 그 시트의 [확장 프로그램 › Apps Script]에서 만든 스크립트인지도 확인.
신청 시간이 9시간 달라요
스크립트 시간대 문제입니다. Apps Script 왼쪽 ⚙️ [프로젝트 설정 › 시간대]를 (GMT+09:00) 서울로 바꾸고 새 버전으로 배포.
동료가 "권한이 없습니다"라고 해요
배포할 때 액세스 권한이 '나만'으로 되어 있습니다. [배포 관리]에서 액세스 범위를 다시 고르세요.
빨간 오류 문구가 나와요
문구를 그대로 복사해서 AI에게 "이렇게 나와"라고 보내세요. 아래 버튼으로 부탁 문장을 복사할 수 있어요.
학교 계정에서 Apps Script 메뉴가 안 보여요
관리자가 막아 둔 경우입니다. 개인 구글 계정으로 시트를 새로 만들어 진행하세요.

실습 7–8 Netlify로 학교에 배포하기

등록 화면만 Netlify로 이사하고, 저장은 구글 시트에 그대로 둡니다.

왜 Netlify까지 배포할까?

⚙️ Apps Script 주소만 쓸 때

script.google.com/macros/s/AKfycbx…(70자 넘게)…/exec

  • 주소가 길어 메신저·QR이 지저분해요
  • 개인 계정이면 화면 위에 'Apps Script 사용자가 만든 앱' 안내가 붙어요
  • 화면이 구글의 틀 안에 들어가 모양이 제한돼요

🌐 Netlify로 올렸을 때

jisan-training.netlify.app

  • 짧고 기억하기 쉬운 주소, 깔끔한 QR

실습 7 Netlify용으로 화면 따로 받기

지금 만든 연수 등록부의 등록 화면만 Netlify에 올리고 싶어. 구조를 이렇게 바꿔 줘. - Code.gs: GET ?action=init → {names, trainings} JSON, POST(JSON 본문 {training, name, hours}) → {ok, message} JSON. 관리 화면(?page=admin)은 지금처럼 Apps Script에 그대로. - 등록 화면: Netlify에 올릴 index.html 한 파일. 맨 위 const SCRIPT_URL = '웹앱 주소' 한 줄만 바꾸면 되게. POST는 Content-Type을 text/plain으로 보내 CORS 오류가 나지 않게. - 시트 구조는 그대로: 명단(이름, 부서), 등록(등록일시, 연수명, 이름, 이수시간), 연수목록(연수명, 마감일). - Apps Script 새 버전 배포 → index.html 저장 → Netlify Drop 순서로 알려 줘.
⚠️ 액세스는 '모든 사용자''조직 내 사용자'로 배포하면 Netlify 화면에서 요청이 막혀요. 대신 Apps Script 주소는 화면 코드 안에만 두고 따로 공유하지 않아요.
